# 每周精选 · 2026-W43 (2026-10-19 ~ 2026-10-25)

## 本周印象
AI 生图轨这周的主题是「先规划、再出图、改哪儿只动哪儿」：Canva 发布自研的首个图像模型 Craft，先让规划模型写出构图方案（元素、空间关系、层级、图内文字），再交给渲染模型出 2K 图；Krea 3 在图像竞技榜冲进前四，主打 8 秒内的 2K 编辑和商品、人物一致性；Bria 的 Fibo 2.0 把生成和编辑合进一个 8B 开源模型，靠结构化 JSON 描述做「只改差异」的编辑。UI·UX·Web 轨则一边是 Awwwards 上 Obys 的 FORMAT 与 makemepulse 为 Cartier 做的 WebGL 叙事站，一边是三篇实用文：NN/g 调研 521 位从业者对 AI 的真实感受，Smashing 讲手风琴图标该怎么选，以及用新的 CSS `random()` 给界面加一点「刻意的不完美」。

## 精选

1. **FORMAT — Obys** · 作品 · UI·UX·Web（实验性排版 / 转场动效）· Awwwards  
   亮点：纯黑白两色的文化教育类实验站，排版驱动，Loading 与页面转场是重点；技术栈 CSS + GSAP + Matter.js（物理效果）。  
   热度依据：Awwwards Site of the Day（2026-10-19）总分 7.59/10（Design 7.85 / Usability 7.2 / Creativity 7.78 / Content 7.38）+ Developer Award 7.54/10；Pro/Chief 用户综合票 9.40（查于 2026-10-25）。  
   归档：https://www.awwwards.com/sites/format

2. **Cartier — Le Chœur des Pierres · makemepulse** · 作品 · UI·UX·Web（奢侈品叙事 / WebGL 滚动）· Awwwards  
   亮点：卡地亚高级珠宝故事站，首页导航、内容页滚动动画和「Gouaché（水粉稿）显影」效果是亮点，用 WebGL 把设计手稿变成可滚动的叙事。  
   热度依据：Awwwards Site of the Day（2026-10-20）总分 7.51/10（Design 7.33 / Usability 7.51 / Creativity 7.71 / Content 7.79）+ Developer Award 7.84/10（本周 SOTD 中开发分最高之一，Accessibility 8.0）；Pro/Chief 用户综合票 9.18。  
   归档：https://www.awwwards.com/sites/cartier-le-choeur-des-pierres

3. **AI in UX: Work Is Faster, But Practitioners Have Mixed Feelings** · 趋势（调研报告）· UI·UX·Web（AI 与设计工作流）· NN/g  
   亮点：Maria Rosala 与 Rachel Banawa 调研 521 位 UX 从业者：99% 能用上 AI，平均觉得任务明显变快（4.2/5），但整体情绪只是「略正面」（3.57/5）；最大障碍是输出质量（54%）和数据隐私（50%）；AI 用得最多的是写代码、桌面研究和数据分析，最少的是跟真实用户打交道的环节；研究员和设计师的职业安全感明显低于 PM。  
   热度依据：Nielsen Norman Group 官方 Articles 专栏 2026-10-23 刊发（权威专栏），并被提交到 Hacker News 讨论。  
   链接：https://www.nngroup.com/articles/ai-in-ux-survey-26/

4. **Accordion Icons: Which Work Best?** · 教程（交互规范）· UI·UX·Web（导航 / 图标语义）· Smashing Magazine  
   亮点：Vitaly Friedman 结合 NN/g 手风琴图标研究给出简单规则：是链接就加下划线，要展开就用 caret；没有图标时用户默认会跳新页；别做「文字跳页、图标展开」的分裂按钮，分类页入口放进展开后的菜单里（例子是 DHL）。  
   热度依据：Smashing Magazine 官方编辑专栏 2026-10-23 刊发（权威专栏）。  
   链接：https://www.smashingmagazine.com/2026/10/accordion-icons-which-work-best/

5. **Embracing Playful Imperfection With The CSS `random()` Function** · 教程 · UI·UX·Web（CSS / 视觉细节）· Smashing Magazine  
   亮点：Brecht De Ruyte 用有机字体、跳动字母、散开的卡片演示原生 CSS `random(min, max, step)`：不用 JS 或 Sass 循环就能给装饰元素加一点随机角度和节奏；同时划清边界，核心布局、正文排版和可点击目标别随机化，并照顾 `prefers-reduced-motion`。目前 Safari 26.2 与 Chrome 156 已支持，Firefox 未支持，建议配 `@supports` 渐进增强。  
   热度依据：Smashing Magazine 官方编辑专栏 2026-10-20 刊发（权威专栏）。  
   链接：https://www.smashingmagazine.com/2026/10/embracing-playful-imperfection-css-random-function/

6. **Canva Craft（Canva 首个自研图像模型）** · 趋势 · AI生图/Prompt（先规划后渲染 / 图内文字 / 设计向）· Canva Newsroom  
   亮点：两阶段架构，先由规划模型写出构图方案（哪些元素、空间关系、相对大小、视觉层级、要出现的文字），再渲染成最高 2K、30 多种比例的图；可只改局部不动其余部分。已在 Canva 的 Dream Lab 对所有用户开放，并提供公开 API，Canva MCP 即将接入。对写 prompt 的启示：把版式和文字当成可核对的清单来写。  
   热度依据：官方 X @canva 发布帖（2026-10-22）约 3,245 赞、1,667 收藏、浏览约 187 万（X API 公开数据，查于 10-25）；TechCrunch 同日报道；官方称首发即位列 DesignArena 图像榜第 4（Elo 1340）。  
   链接：https://www.canva.com/newsroom/news/canva-craft/ ｜ https://x.com/canva/status/2113348707223753165

7. **Krea 3（Fast / Ultra）登上图像竞技榜** · 趋势 · AI生图/Prompt（图像编辑 / 商品与人物一致性）· Krea  
   亮点：Krea 3 主打快速编辑，多数编辑 8 秒内返回原生 2K，每次最多 6 张参考图，换场景时商品标签和人物长相保持不变，2K 单价 $0.06，适合电商目录和大量变体。10-20 官方宣布 Ultra 冲进图像竞技榜前四，Fast 在速度与质量的平衡上领先。  
   热度依据：官方 X @krea_ai 帖（2026-10-20）约 1,665 赞、1,175 收藏、浏览约 131 万（X API 公开数据，查于 10-25）；第三方 @Lummox_eth 转引 Artificial Analysis 初步榜单称 Krea 3 Ultra 1151 Elo，仅比 Nano Banana 2.1 低 1 分。模型本身于 10-15 发布。  
   链接：https://www.krea.ai/blog/introducing-krea-3 ｜ https://x.com/krea_ai/status/2112567020353102324

8. **Bria Fibo 2.0（8B 开源，生成 + 编辑合一）** · 趋势 / 工作流 · AI生图/Prompt（结构化 JSON 提示词 / 局部编辑）· Bria AI  
   亮点：一个 8B 模型同时做文生图、指令编辑、蒙版编辑和最多 4 图参考合成；沿用结构化 JSON caption（光线、机位、景深、每个物体各占字段），编辑等于改这份「蓝图」的差异，其余部分保持不动。开源 Dev 与 4 步蒸馏 Edit Turbo 两个权重（CC BY-NC 4.0，商用需另签），训练数据全部为授权数据。  
   热度依据：官方称位列 Artificial Analysis 开源权重图像编辑榜第 1；官方 X @bria_ai_ 发布帖（2026-10-20）约 255 赞、101 收藏、浏览约 1.8 万；fal 上线帖约 192 赞、浏览约 1.5 万；@aisearchio 实测帖约 534 赞、365 收藏、浏览约 2.2 万（X API 公开数据）。  
   链接：https://aicoder.com/news/news-20261021-bria-fibo-2-0-open-weights-8b-image-editing-model ｜ https://x.com/bria_ai_/status/2112559473458045305
