# 每周精选 · 2026-W38 (2026-09-14 ~ 2026-09-20)

## 本周印象
本周主线仍是 **Agent / 意图驱动界面** 与 **可辩护的 UX 价值**：L.I.S.A. 把虚拟助手做成可逛的对话产品站；Smashing 一边谈「按钮之死」与 Generative UI，一边教你怎么把 onboarding 改版讲成董事会听得进的 ROI。作品侧，Aspen Search、Boc.Studio 与 Kononenko 分别示范极简企业站、工作室连续表面导航，以及多模式作品浏览。教程上，Coinbase × Figma Code Connect 给出设计系统服务 Agent 的可复现对照实验。

## 精选

1. **Aspen Search** · 作品 · Awwwards  
   亮点：量化招聘精品站——主题切换、轮播+模态、彩纸微交互，把「找人」做成干净可感知的单页体验。  
   热度依据：Awwwards Site of the Day（2026-09-15）；SOTD 总分 7.48/10；同获 Developer Award（7.32/10）。  
   作品：https://www.aspensearch.com  
   归档：https://www.awwwards.com/sites/aspen-search

2. **L.I.S.A.** · 作品 · Awwwards / Locomotive  
   亮点：把虚拟助手做成可逛的叙事产品站——对话 UI、3D 与 microcopy 一起讲清「助手如何帮你做事」。  
   热度依据：Awwwards Site of the Day（2026-09-16）；SOTD 总分 7.48/10；同获 Developer Award（7.52/10）。直接覆盖 conversational / Agent UX。  
   作品：https://lisa.locomotive.ca/en  
   归档：https://www.awwwards.com/sites/l-i-s-a

3. **Boc.Studio** · 作品 · Awwwards  
   亮点：巴塞罗那品牌工作室站做成连续表面——项目行上的速度爆发与案例滑入，手感全在 hover 与交接。  
   热度依据：Awwwards Site of the Day（2026-09-19）；SOTD 总分 7.23/10；同获 Developer Award（7.3/10）。  
   作品：https://boc.studio/  
   归档：https://www.awwwards.com/sites/boc-studio

4. **Kononenko Architectural Bureau** · 作品 / 案例 · Codrops / Awwwards  
   亮点：同一批建筑项目，Grid / List / Active Gallery 三种浏览关系；素描与 WebGL 让过程本身成为界面。  
   热度依据：Awwwards SOTD（总分 7.27）+ Developer Award（7.59）；另获 The FWA of the Day、GSAP SOTD / SOTW、Behance UI Featured；Codrops 于 2026-09-18 刊发正式 Making-of。  
   作品：https://kononenkogroup.com/  
   深度案例：https://tympanus.net/codrops/2026/09/18/kononenko-architectural-bureau/  
   归档：https://www.awwwards.com/sites/kononenko-architectural-bureau

5. **The Death Of The Button: Why The Best Interface Is No Interface** · 趋势 · Smashing Magazine  
   亮点：从点选按钮转向表达意图——用 Perplexity、v0、Goblin.tools 说明 Generative UI 如何把复杂流程收成一句目标。  
   热度依据：Smashing Magazine 2026-09-09 编辑部正式刊发（UX / Design / AI 栏目）；权威行业媒体编辑推荐，本周仍居文章流前列。  
   链接：https://www.smashingmagazine.com/2026/09/death-button-why-best-interface-is-no-interface/

6. **Building A UX ROI Case That Survives The Boardroom** · 趋势 · Smashing Magazine  
   亮点：用贯通数字的 B2B SaaS 案例，把 onboarding 改版从「好用」讲成可辩护的约 5:1 ROI。  
   热度依据：Smashing Magazine 2026-09-11 编辑部正式刊发（UX 栏目，约 14 分钟长文）；权威媒体编辑推荐。  
   链接：https://www.smashingmagazine.com/2026/09/building-ux-roi-case-survives-boardroom/

7. **How Coinbase used Code Connect to guide agents and shrink token costs** · 教程 · Figma Blog  
   亮点：当设计系统主用户变成 Agent，Coinbase 用 Code Connect + Figma MCP 塞进组件上下文；对照实验显示平均降 token 成本约 22.5%。  
   热度依据：Figma 官方博客 2026-09-02 编辑部正式刊发；Coinbase Design System 团队公开实测数据（token / 耗时 / 组件选型），非随机冷门帖。  
   链接：https://www.figma.com/blog/how-coinbase-used-code-connect-to-shrink-token-costs/

8. **Cerebrium** · 作品 · Awwwards  
   亮点：AI serverless 产品站——WebGL、微交互与透明定价计算器，把冷启动与扩缩讲成可感知界面。  
   热度依据：Awwwards Site of the Day（2026-09-10）；SOTD 总分 7.39/10；同获 Developer Award（7.5/10）；本周每日精选归档引用。  
   作品：https://cerebrium.ai  
   归档：https://www.awwwards.com/sites/cerebrium
