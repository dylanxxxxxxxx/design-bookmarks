# 每周精选 · 2026-W44 (2026-10-26 ~ 2026-11-01)

## 本周印象
这周 UI·UX·Web 轨的关键词是「用户不一定是人了」：NN/g 同一天发了两篇文章，一篇主张把 User Experience 扩成 Experience Design，因为越来越多的交互由替人办事的 AI 代理完成；另一篇拆解 Anthropic 等公司提出的 AI 原生开发流程，指出 UX 被压缩成「喂给 AI 的上下文」，并给出 UX 团队能马上做的事。作品方面，Awwwards 本周得分最高的两站都是 Three.js 驱动的 3D 交互：A24 片单的唱片式浏览实验，以及巴黎开发者 Guillaume Colombel 的作品集。AI 生图轨延续「只改该改的地方」：Ideogram 推出局部精修窗口，Microsoft 的 MAI Image 2.6 上线 Foundry、2.7 Preview 冲到编辑榜第 2；教程方面，一条「一个 prompt 出整张分镜板，再交给视频模型」的工作流在 X 上被大量收藏。

## 精选

1. **A24 — Ravi Klaassens** · 作品 · UI·UX·Web（3D 交互 / 影片目录浏览）· Awwwards  
   亮点：非商业的实验项目，把 A24 的片单做成一张张可旋转、可翻找的 3D 唱片，围绕「发现代表作」组织浏览；404 页和加载动画也是看点。技术栈 Three.js + GSAP + Barba.js。  
   热度依据：Awwwards Site of the Day（2026-10-26）总分 7.65/10（四项分别为 7.65 / 7.31 / 8.01 / 7.95，创意分最高）+ Developer Award 7.41/10，是本周 SOTD 中总分最高的一站（查于 2026-11-01）。  
   归档：https://www.awwwards.com/sites/a24

2. **G. Colombel — Portfolio 2026** · 作品 · UI·UX·Web（创意开发者作品集 / WebGL 转场 / 声音）· Awwwards  
   亮点：巴黎自由职业交互开发者 Guillaume Colombel 的作品集，页面转场是重点，配合声音和 3D，适合参考「作品集如何用动效讲清楚自己会什么」。技术栈 WebGL + Three.js + JavaScript。  
   热度依据：Awwwards Site of the Day（2026-10-28）总分 7.5/10（7.56 / 7.27 / 7.81 / 7.35）+ Developer Award 7.73/10，其中 Animations/Transitions 单项 8.4，是本周 SOTD 开发分最高之一。  
   归档：https://www.awwwards.com/sites/g-colombel-portfolio-2026

3. **Experience Design: Dropping the "User" from "User Experience"** · 趋势（观点）· UI·UX·Web（AI 代理与体验设计）· NN/g  
   亮点：Raluca Budiu 认为 AI 正在改变 UX 最基本的假设，也就是「和产品打交道的是人」。以后买菜、投诉、订机票可能由用户的个人代理去完成，而且发生在企业设计好的渠道之外。所以她主张用 Experience Design 来指这个更宽的领域，但核心仍是人的目标。  
   热度依据：Nielsen Norman Group 官方 Articles 专栏 2026-10-30 刊发（权威专栏）。  
   链接：https://www.nngroup.com/articles/ux-vs-experience-design/

4. **The Role of UX in Agentic Software Factories** · 方法论 / 案例研究 · UI·UX·Web（AI 原生开发流程中的 UX）· NN/g  
   亮点：Tanner Kohler 以 Anthropic 2026 年 8 月发布的 AI 原生软件开发流程（并对照 Google、OpenAI 的类似文档）为例，指出这些流程都把 UX 降成「指导 AI 生成的背景上下文」。文章主张 UX 仍要承担三件事：发现用户需求、帮团队判断该做什么、在上线前后评估结果，并列出 6 件今天就能开始做的事。  
   热度依据：Nielsen Norman Group 官方 Articles 专栏 2026-10-30 刊发（权威专栏）。  
   链接：https://www.nngroup.com/articles/ux-agentic-software-factories/

5. **Tabs Used Right（视频）** · 教程（交互规范）· UI·UX·Web（导航 / 组件）· NN/g  
   亮点：5 分钟讲清什么时候该用标签页，以及「导航标签」（切换到不同页面）和「页内标签」（同一页切换内容）的区别，适合和上周 Smashing 的手风琴图标文章一起看。  
   热度依据：Nielsen Norman Group 官方视频专栏 2026-10-26 发布（权威专栏）。  
   链接：https://www.nngroup.com/videos/tabs-used-right/

6. **Ideogram 局部精修窗口（context window for precise edit）** · 趋势（新功能）· AI生图/Prompt（高分辨率局部编辑）· Ideogram  
   亮点：在超高分辨率图里框出任意区域（最大 2K）单独重画，窗口外的像素完全不动，官方主打「没有接缝、没有瑕疵、不用 Photoshop」。App 和 API 同时上线。对大幅海报、电商长图这类「只改一块」的场景很实用。  
   热度依据：官方 X @ideogram_ai 发布帖（2026-10-29）约 351 赞、163 收藏、浏览约 2.6 万（X API 公开数据，查于 2026-11-01）。  
   链接：https://x.com/ideogram_ai/status/2115843973889839388

7. **Microsoft MAI Image 2.6 正式上线 + MAI Image 2.7 Preview** · 趋势 · AI生图/Prompt（文字渲染 / 商业写实 / 图像编辑）· Microsoft AI  
   亮点：Microsoft 官方称 MAI Image 2.6 在 Arena 文生图榜排第 2，比 2.5 整体提升 79 Elo，图内文字渲染提升 91 Elo，重点改进人像、3D 和产品、品牌类写实图；2.6 与更快更便宜的 2.6 Flash 已在 Microsoft Foundry 正式可用。同日 2.7 Preview 编辑模型上线 Arena 和 MAI Playground。  
   热度依据：Artificial Analysis 官方 X 帖（2026-10-27）称 MAI-Image-2.7-Preview 位列其 AA-Image-Editing v2.1 榜第 2，约 490 赞、93 收藏、浏览约 75.3 万；官方 X @MicrosoftAI 上线帖（2026-10-27）约 273 赞、浏览约 1.6 万；@testingcatalog 转引称 2.7 Preview 在 Image Editing Arena 排第 3（约 238 赞、浏览约 1.4 万）。（X API 公开数据，查于 2026-11-01）  
   链接：https://microsoft.ai/news/mai-image-2-6-launches-at-no-2-on-arena-ahead-of-google-meta-and-xai/ ｜ https://x.com/ArtificialAnlys/status/2115097540320506069

8. **一个 prompt 出整张分镜板：GPT Image 2.5 + Seedance 2.5 动画工作流** · 教程 / 工作流 · AI生图/Prompt（分镜 prompt 写法 / 图生视频）· X @HeyAbhishek  
   亮点：第一步在 ChatGPT 里用 GPT Image 2.5，一个 prompt 生成一整张竖版「动画开发板」，包含 8 个镜头的分镜和角色设定；第二步把这张图作为参考上传给 Seedance 2.5，用另一段 prompt 要求「按分镜顺序走 8 个镜头、保持角色和道具一致」，生成 15 秒动画。两段 prompt 都在帖子里完整给出，可以直接拿来改。值得学的是把「一张图」当成后续生成的规格书。  
   热度依据：X 主帖（2026-10-28）约 327 赞、343 收藏、78 转发、浏览约 1.9 万，收藏数高于点赞数，说明被当成教程收藏（X API 公开数据，查于 2026-11-01）。  
   链接：https://x.com/HeyAbhishek/status/2115429393967550598
