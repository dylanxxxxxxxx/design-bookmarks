5. **The Drive: Building a Resident Evil Concept for the Webflow × GSAP × CodeTV Challenge** · 案例 / 教程 · Codrops  
   亮点：以「快递一夜」为结构的滚动着陆页——从雨刷 sketch 长成完整叙事；血滴引擎、红线城市与硬边缘消解，都可对照复盘。  
   热度依据：Codrops Case Studies 专栏 2026-09-29 正式刊发；作者自述获 Webflow × GSAP × CodeTV 挑战 first place（Webflow 机械键盘 + GSAP swag）。  
   作品：https://re-the-drive.webflow.io/  
   深度案例：https://tympanus.net/codrops/2026/09/29/webflow-gsap-codetv-challenge/

6. **GPT Image Generation Models Prompting Guide** · 教程 · OpenAI Developers Cookbook  
   亮点：别把 Prompt 写成灵感独白——按「场景 → 主体 → 细节 → 约束」写清，并在每次编辑里显式复述「改什么 / 保留什么」。  
   热度依据：OpenAI 官方 Developers Cookbook 专栏正式刊发；仓库 `openai/openai-cookbook` 公开 star≈76,251（查于 2026-09-29）。  
   链接：https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide

7. **FLUX Prompting Guide — Official Black Forest Labs** · 教程 · Black Forest Labs Docs  
   亮点：FLUX 不吃负向提示和关键词堆砌——用「图像类型 → 主体 → 场景 → 风格 → 镜头 → 光照 → 色彩」写清自然语言，再按「改一处、留一处」迭代。  
   热度依据：Black Forest Labs 官方文档专栏正式刊发（`docs.bfl.ml/guides/prompting_summary`）；配套 `black-forest-labs/skills` 公开 star≈122（查于 2026-10-01）。  
   链接：https://docs.bfl.ml/guides/prompting_summary

8. **Ideogram Prompting Guide — Official Docs (Plain Language + JSON)** · 教程 · Ideogram Docs  
   亮点：Ideogram 把提示当字面说明书——句子写清关系、主意放前；要精确排版与品牌色时，用 JSON（或 Magic Prompt）控制 bbox、图内文字与 `#RRGGBB` 色板。  
   热度依据：Ideogram 官方文档专栏正式刊发（`docs.ideogram.ai/prompting/prompting`）；配套开源仓库 `ideogram-oss/ideogram4` 公开 star≈2864（查于 2026-10-03）。  
   链接：https://docs.ideogram.ai/prompting/prompting
