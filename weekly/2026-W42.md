3. **What telephones can tell you about good design** · 案例研究（方法论）· UI·UX·Web（可用性研究 / 心智模型）· UX Collective  
   亮点：Bell Labs 测试多种按键布局，用户最快、最少出错、最喜欢的都不是最终方案，胜出的是最符合「从左到右、从上到下」心智模型的 3×3+1；计算器把小数字放底部则对应真实数据分布。核心教训是看真实任务表现，别只听自述偏好。  
   热度依据：本周热度飙升，2026-10-12 @SandyofCthulhu 键盘布局帖约 33,082 赞、3,940 收藏、浏览约 238 万（X API 公开数据）；@pitdesi 引用并直接推荐本文（约 53 赞、2.3 万浏览）；原文由 UX Collective 刊发（2024-05），曾入选 Sidebar.io 与 TLDR Design 当期精选。  
   链接：https://uxdesign.cc/what-telephones-can-tell-you-about-good-design-6c24885ca7e9 （每日栏 daily/2026-10-15）

4. **Synthetic Users vs. Human Respondents: Same Conclusion, Less Variation** · 趋势（研究 / 方法论）· UI·UX·Web（AI 与用户研究）· NN/g  
   亮点：Rachel Banawa 把一道开放题同时问 604 位真人从业者和 120 个 Synthetic Users 平台生成的合成受访者：两边结论一致，但合成答案用词范围窄得多（作者称之为 mode collapse），平台还会自行改写问题措辞。结论是合成用户研究仍不能替代真实用户研究，可用于预演，不能用来收敛结论。  
   热度依据：Nielsen Norman Group 官方 Articles 专栏 2026-10-16 刊发，基于一手对比数据（权威专栏）。  
   链接：https://www.nngroup.com/articles/synthetic-users-vs-human-respondents/

5. **Midjourney Thinking Mode（测试）** · 趋势 · AI生图/Prompt · Midjourney Updates  
   亮点：V8.2 的生成与 Edit 任务都能点「Rerun (Thinking)」，模型回看自己的图，找漏掉的物体、错乱的版式与文字错误后重画；生图开始借鉴 LLM 的「生成、自评、修正」闭环，写 prompt 时把数量、位置、引号内文字写成可核对的清单更划算。  
   热度依据：Midjourney 官方 Updates 2026-10-08 以「New」刊发，Alpha Changelog 列为头条；官方 X 帖截至 10-12 约 862 赞、247 收藏、浏览约 60,522（X API 公开数据）。  
   链接：https://www.midjourney.com/updates/testing-thinking-mode （每日栏 daily/2026-10-12）

   亮点：10-01 闭源 FLUX 3 Image 把画布当 0–1000 网格，用 JSON bounding box 指定每个元素位置，未改动像素尽量保持不变；10-15 同族 5.6B 开源 Klein 落地，INT8 可在 8GB 显存跑，保留布局、多参考合成与原生 4K，Hugging Face Diffusers、ComfyUI 当天接入。
