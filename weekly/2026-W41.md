   亮点：把无人机原始 LIDAR 扫描变成浏览器里实时渲染的 3D 点云，滚动、菜单转场与地形扫描都可当作交互参考。

   作品：https://drone.riotters.com/  
   归档：https://www.awwwards.com/sites/lidar-drone-scanning

2. **Maria Vasilyeva Portfolio** · 作品 · UI·UX·Web（作品集 / 交互排版）· Awwwards  
   亮点：以音乐与声音为灵感的交互式设计师作品集，节奏、字体排印、布局、悬停与项目页交互连成一体。

   作品：https://www.mariavasilyeva.com/  
   归档：https://www.awwwards.com/sites/maria-vasilyeva-portfolio

3. **The New Big Ball of Mud: Why Agentic AI Systems Turn Fragile** · 趋势（深度文）· UI·UX·Web（Agent UX / 人机协作）· NN/g  
   亮点：Tanner Kohler 用 1997 年软件工程概念「大泥球」解释 vibe architect 的 Agent 工作流为何越堆越脆，并给出 Global / Local / Ambient 三类上下文的维护习惯。  
   热度依据：Nielsen Norman Group 官方 Articles 专栏 2026-10-02 刊发，基于一手用户研究（权威专栏）。  
   链接：https://www.nngroup.com/articles/big-ball-of-mud-ai/

4. **A Practical Guide To Naming Things** · 教程（方法论 + 资源清单）· UI·UX·Web（设计系统 / Design Tokens）· Smashing Magazine  
   亮点：主编 Vitaly Friedman 把颜色、图层、组件、Token、变量到产品名的命名方法与工具整理成一份可收藏的速查表。  
   热度依据：Smashing Magazine 官方编辑栏目 2026-10-06 刊发、主编亲撰；随站点 182,000+ 订阅的每周邮件推送。  
   链接：https://www.smashingmagazine.com/2026/10/how-name-things/

5. **Midjourney Edit Model — Official Docs（V8.2）** · 教程 / 趋势 · AI生图/Prompt · Midjourney Docs  
   亮点：提示词从「描述一幅画」扩展到「下指令改图」，一个模型同时承担指令改图、最多 4 张参考图合成与局部重绘/扩图。  
   热度依据：Midjourney 官方文档专栏；Edit 是 V8.2（2026-07-24 起默认版本）的核心功能，官方明确取代 Omni Reference、Character Reference 与 Retexture，属平台级默认工作流变更。  
   链接：https://docs.midjourney.com/hc/en-us/articles/48495453462797-Edit-Model

6. **awesome-gpt-image-2 — Prompt as Code** · 作品（案例库）+ 教程 · AI生图/Prompt · GitHub  
   亮点：544 个可复现 GPT Image 2 / 2.5 案例 + 20 多套结构化模板，其中 UI 与界面类 73 例，可直接连到 UI 概念稿工作流；另有 2.5 同提示词对比专区。  
   热度依据：GitHub 星标约 34,001（查于 2026-10-07），相关检索按星标排第 1；README 带 Trendshift 趋势榜徽章。  
   链接：https://github.com/freestylefly/awesome-gpt-image-2

7. **Prompting with Recraft V4** · 教程 · AI生图/Prompt（矢量 / Logo / 海报排版）· Recraft Docs  
   亮点：短提示让模型一起设计，长提示让模型执行你的视觉架构；矢量、海报层级与图内文字都有可套用的写法顺序。  
   热度依据：Recraft 官方 Docs 专栏刊发，配套 Recraft Blog 由 AI Designer Anna Abdulina 正式刊发（2026-03-11）。  
   链接：https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4
