## 一句话亮点

闭源 FLUX 3 Image（10-14 已推）承诺的 Open Weights 如期落地——5.6B 参数、INT8 可跑在 8GB 显存消费卡上，却保留 Bounding Box 布局、多参考合成与像素级局部编辑；短 prompt 必须先经 Prompt Upsampler 扩成完整 scene caption，否则输出偏泛。

## 可学点

- **趋势信号**：开源侧从「越大越好」转向「更小、更快、可本地微调」——Klein 在内部评测中自称高于 Qwen-Image 2.1（开源榜）甚至 Ideogram V4.5 / FLUX.2 [pro]（闭源对照），同时把布局 JSON 与多参考做成一等公民。
- **对写 prompt 的影响**：模型吃的是完整场景描述（主体、环境、光线、构图、风格），不是关键词堆叠；编辑时把改动写进「目标图的完整 caption」；布局则在 caption 后追加 `[{"id","bbox","desc"}]`（坐标 `[y_min,x_min,y_max,x_max]`，0–1000 网格）。
- **试用路径**：HF 下载 `flux-3-image-klein`（蒸馏，16 steps）或 `flux-3-image-klein-base`（微调/研究）；Diffusers ModularPipeline、ComfyUI 模板、BFL API `flux-3-image-klein`（约 $0.009 / 1K 图）均可上手；LoRA 可用 Ostris AI Toolkit / Diffusers DreamBooth 脚本。
- **与既有推送区分**：10-14 为闭源 FLUX 3 Image API/产品上线（趋势）；今日为同族 **Open Weights Klein** 正式开源（趋势），聚焦消费级本地部署、Prompt Upsampler 与开源生态 day-0 接入。
