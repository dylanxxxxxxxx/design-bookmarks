- **热度依据**：Google Cloud Blog / Vertex AI 官方专栏正式刊发（2026-03-05）——权威官方长文，覆盖 Nano Banana 2（Gemini 3.1 Flash Image）与 Nano Banana Pro（Gemini 3 Pro Image）的 prompting 框架、规格与案例；被 Vertex AI Creative Studio 等官方材料引用，并出现二次转载/摘要（如 Scribd、第三方解读文）。今日双轨轮到 AI 生图/Prompt（昨日为 UI·UX·Web / bleibtgleich’26 Codrops 案例）；内容类型选官方 Prompt 方法论教程，与 9/21 的 4W1H、9/23 的八模型横评、9/25 的跨模型句式教程区分（聚焦 Google 生图模型的导演式提示与多模态编辑）。
- **一句话亮点**：别再堆关键词——用导演式自然语言写清 Subject / Action / Location / Composition / Style，再靠对话式编辑精修，而不是整图重抽。
- **可学点**：1）文生图公式 `[Subject] + [Action] + [Location/context] + [Composition] + [Style]`，并以强动词开场；正向描述想要的画面（如 empty street），少写「不要什么」；2）多模态参考图要写清每张图的角色（结构 / 材质 / 场景），编辑时显式声明「保留什么、改什么」；3）文字渲染把精确文案放引号并指定字体/字重，复杂文案可先让模型写文案再出图；结合相机、布光、胶片与材质术语提升可控性。
