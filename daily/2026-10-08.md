- **一句话亮点**：命名是设计系统里最被低估的协作成本——这篇把颜色、图层、组件、Design Token、变量、新功能乃至产品名的命名方法和工具一次性整理成可直接收藏的清单。
- **可学点**：
  1. 好名字的标准（引 Javier Cuello）：结构有逻辑、短、有含义、全员都懂，且**不绑定视觉属性**（别叫 `blue-button`，要叫语义名）。
  2. Design Token 命名可参考三套真实体系：Intuit 的灵活 token 分类法（Nate Baldwin 案例研究）、Vodafone UK 的 Variables Taxonomy Map（brand → primitives → semantics → pages 四个集合），以及 Romina Kavcic 的免费 Token 命名生成器 + 四级 Token 清单表。
  3. 给 UI 组件起名前先查 Component Gallery（收录 50+ 组件在各设计系统中的别名）和 Name That UI；给新功能起名要用用户自己的话——让用户用自己的语言解释这个功能，再采纳他们的用词（引 Erin Gannon）。
  4. 功能采用率低，有时只是名字问题；团队里设计师、开发、PM、用户各说各的「方言」，统一命名能直接降低沟通摩擦。
