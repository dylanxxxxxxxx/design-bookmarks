## 一句话亮点

生图不再只靠「把 prompt 写得更长」——把画布当成 0–1000 网格，用 JSON bounding box 指定每个元素的位置与描述，未改动的像素尽量数值级保持不变；布局控制直接写进 prompt，为 agent / 代码管线而生。

## 可学点

- **趋势信号**：从「自然语言碰运气」走向「结构化布局 + 像素级局部编辑」——与 Midjourney Thinking、GPT Image 精确编辑同一方向，但 FLUX 3 Image 把坐标网格与多参考合成做成一等公民 API。
- **对写 prompt 的影响**：全局一句 scene caption + 元素表（`id` / `bbox` / `desc`）；图内文字、人物、面板各自成 box；编辑时显式写「改什么、留什么」，未点名区域更容易锁住。
- **试用路径**：Playground 手动画框，或 API `POST /v1/flux-3-image`；也可用 Vercel AI Gateway 的 `bfl/flux-3-image`（无需单独 BFL 账号）。分辨率档：`768sq` → `4k`。
- **与既有推送区分**：10-01 为 FLUX.1/2 官方 Prompting Guide（教程）；今日为 FLUX 3 Image 新品能力上线（趋势），聚焦 bounding box 布局与像素锁定编辑。
