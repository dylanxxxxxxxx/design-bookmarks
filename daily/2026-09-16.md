# 每日精选 · 2026-09-16

- **标题**：How Coinbase used Code Connect to guide agents and shrink token costs
- **类型**：教程
- **来源**：Figma Blog
- **链接**：https://www.figma.com/blog/how-coinbase-used-code-connect-to-shrink-token-costs/
- **热度依据**：Figma 官方博客 2026-09-02 编辑部正式刊发；Coinbase Design System（CDS）团队实测案例，公开数据：Code Connect 平均降低 token 成本 22.5%、实现耗时约 22.3%、token 用量约 11.5%。主题直接覆盖设计系统 + Agent / design-to-code，非随机冷门帖。
- **一句话亮点**：当设计系统的「主用户」从工程师变成 Agent，Coinbase 用 Code Connect + Figma MCP 把组件上下文塞进生成流程，用对照实验证明更省 token、更快、更贴 CDS。
- **可学点**：1）把 Code Connect 映射当作 Agent 的设计系统入口，而不是事后补丁；2）用同一设计 / 同一 prompt / 对照重置做可复现评测（token、耗时、组件选型）；3）区分 agent skills（规范行为）与 Code Connect（设计上下文）——两者职责不同，可叠加。
