- **一句话亮点**：别把 Prompt 写成灵感独白——按「场景 → 主体 → 细节 → 约束」写清，并在每次编辑里显式复述「改什么 / 保留什么」，才扛得住生产级迭代。
- **可学点**：1）文生图用稳定顺序：background/scene → subject → key details → constraints，并写明用途（广告 / UI mock / 信息图）以切换「模式」；需要写实时直接写 `photorealistic`，相机参数当构图线索而非物理保证；2）图内文字把原文放引号或 ALL CAPS，并约束字体/字号/位置；小字与密集版式优先 `quality=medium/high`；3）编辑工作流用「change only X」+ 保留清单（identity / geometry / layout / brand），多图输入按序号标明角色（主体 / 风格 / 服装），一次只改一件事再迭代，避免长 Prompt 一次堆崩。
